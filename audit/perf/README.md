## ⚠️⚠️ この数は「あの PC の、あの構成の」数

- **Release でしか意味がない**（第136〜141 の床は全部 Debug の数＝別物。構成をラベルに書くこと）。
- **機械が変われば絶対値は変わり、支配項が入れ替われば順位も変わる。**
  ⇒ **別の PC で取った数と並べて比較しない。** A/B は必ず**同一窓・同一機・同一 binary**で。
- ここに残してあるのは**記録**であって、新しい環境の基準線ではない。
  新しい環境の順位は**取り直してから**書くこと（▶ の但し書きと同じ）。
- ⚠️ **ベンチを回す前に一声かける**（共有 PC・[RULES](../../docs/RULES.md)）。
  **1 サンプル目は捨てる。**

A/B を回すスクリプト自体は `../lpreg/perf-ab*.ps1`。
