# ABC 記法の読み込み（設計メモ）

オーナー決定 2026-11-18:「すぐ作れる importer」として ABC 記法（`.abc`）を作る。

## 1. 形

- 読み手は `LilySharp.Core/MusicXmlImport/AbcReader.cs` の 1 つだけ。MusicXML・MIDI と同じ中間形
  `ImportDocument` を埋め、`.lys` は `LysWriter` が書く（音高の綴り・小節・弱起・繰り返し・歌詞・
  コード名・報告はすべて今あるもの）。
- 入口は `MusicXmlImporter.ImportBytes` のまま。中身で見分ける（MIDI はヘッダ・mxl は zip・XML は `<`。
  そのどれでもなく、`K:` の行を持ち、最初の意味のある行が `X:` か `T:` などの欄のテキストなら ABC）。
  ＝CLI の `lysc import`・LSP の `lilysharp/importMusicXml`・エディタのコマンドは呼び方を変えない。
- エディタ: `Import MusicXML or MIDI…` を `Import MusicXML, MIDI or ABC…` に改め、ファイル選択の
  フィルタとエクスプローラーの右クリックに `.abc` を足す。File > New File… の集約した項目の名前にも ABC を入れる。

## 2. 読む範囲（ABC 2.1 の、よく使われるところ）

| 種類 | 読むもの | 書き方 |
|---|---|---|
| 見出し | `T:`（1 つ目は曲名・2 つ目は副題）・`C:` 作曲者・`M:`・`L:`・`Q:`・`K:` | `title`・`subtitle`・`composer`・`time`・`tempo`・`key` |
| 拍子 | `n/m`・`C`（4/4）・`C\|`（2/2）・`2+3/8`（和を取る・報告） | `time` |
| 基本の長さ | `L:`。無ければ拍子が 3/4 未満なら 1/16、それ以外は 1/8（2.1 の規則） | — |
| テンポ | `1/4=120`・`3/8=60`・`120`（L を拍に）・`"Allegro" 1/4=120` | 4 分音符の数に直す・言葉は `tempo "…"` |
| 調 | 主音（`#`/`b`）＋旋法（maj・min・m・dor・phr・lyd・mix・aeo・loc・ion。先頭 3 文字で読む）・`none`・`clef=bass` など | `key d dorian`・`clef` |
| 音符 | `^` `^^` `_` `__` `=`、`C`〜`B`（4 オクターブ目）・`c`〜`b`（5）、`'` `,`、長さ `2` `/` `//` `3/2` `/4` | 音高は絶対・長さは値と付点、表せない長さはタイでつなぐ |
| 臨時記号の効き方 | 同じ小節の同じ音高（文字とオクターブ）に効く・タイで次の小節へ続く音にも効く（2.1 の本文はオクターブについて書いていない＝五線譜の慣習に合わせた） | 音高に焼き込む |
| 休符 | `z`・`x`（見えない＝スペーサ）・`Z`/`Zn`（小節休符・n 小節） | `r`・`s`・`R` |
| 和音 | `[CEG]`・`[CEG]2`（長さは最初の音の長さ×外の長さ） | `< >` |
| 付点のリズム | `>` `<` `>>` `<<` `>>>` | 長さに焼き込む |
| 連符 | `(3abc`・`(p:q:r`（q を省けば 2.1 の表） | `tuplet p/q { }` |
| タイ・スラー | `-`・`( )`（入れ子の 2 つ目以降は報告して落とす） | `~`・`( )` |
| 装飾音 | `{g}`・`{/g}`（斜線＝acciaccatura） | `grace { }`・`acciaccatura { }` |
| 小節線 | `\|` `\|\|` `[\|` `\|]` `\|:` `:\|` `::` `:\|:` `:\|\|:` `.\|` | 小節・複縦線・終止線・繰り返し |
| 括弧 | `[1` `[2` `\|1` `:\|2` `[1,3`（最初の数を使う・報告） | 1 番・2 番括弧 |
| 記号 | `.` スタッカート・`~` ターン（アイリッシュ・ロール）・`H` フェルマータ・`T` トリル・`L` アクセント・`M` モルデント・`P` プラル・`u` `v` 弓・`!…!` / `+…+` の長い形（強弱 `p`〜`fff`・`mp` `mf` `sfz`、`crescendo(` `<(` ほか） | `@staccato` など |
| コード名 | `"Am7"` `"G/B"` | `@chord(Am7)`（読めない名前は文字のまま・報告） |
| 注釈 | `"^text"`（上）・`"_text"`（下）・`"<text"` `">text"` `"@text"`（上として） | `@text("…")` |
| 欄（本文の中） | `K:` `M:` `L:` `Q:` `V:` の行と `[K:…]` などのインライン | 途中の変化 |
| 声部 | `V:` ごとに 1 つのパート（譜表）。`name="…"`・`nm=` を譜表の名前に・`clef=` | `part`・`staff "…"` |
| 歌詞 | `w:`（空白・`-`・`_`・`*`・`~`・`\|`・`\-`）を直前の音楽の行の音へ。タイの 2 つ目の音にも 1 音節（2.1 §5.1「tied … notes are treated as separate notes」）・休符と装飾音には付けない・`\|` は音節が足りないときだけ次の小節へ。同じ行に続く `w:` は 2 番・3 番 | 歌詞のブロック |
| 続き | 行末の `\`・`%` のコメント・`%%` の指示（読み飛ばす） | — |

## 3. 何曲も入ったファイル（曲集）

オーナー決定 2026-11-18:「選ぶよりも複数枚の `.lys` を作る」。Lily# の 1 ファイルは 1 曲
（`title`・`time`・`key`・`form` はファイルに 1 つ。複数の `score` は同じ音楽の版違い）なので、曲集を 1 枚にはしない。

- `X:` から次の `X:` の手前までが 1 曲（`AbcReader.SplitTunes`）。最初の `X:` より前の欄（ファイルの見出し。
  `T:` を除く）は、どの曲にも曲自身の見出しの前に入れる＝曲自身の欄が勝つ。
- 曲が 2 つ以上なら、元のファイルの隣に同じ名前のフォルダを作り（`reels.abc` → `reels/`）、曲ごとに
  `001-speed-the-plough.lys` を書く（`AbcReader.FileNames`）。番号は `X:` の数（3 桁以上・曲集の一番大きな数の桁に
  揃える）、続けて曲名を小文字にし、文字と数字（どの文字体系でも）のほかを 1 つのハイフンにしたもの（60 字まで）。
  `X:` が無い・重なるときは曲集の中の位置から空いている番号、同じ名前は `-2` `-3`。
- 読めない曲は飛ばして理由を言い、ほかの曲は書く（`MusicXmlImporter.ImportPieces`）。
- CLI: `lysc import reels.abc` は `reels/` に書く（`-d` ならその下）。全部書けたら終了コード 0、飛ばした曲があれば 1。
- エディタ: パレットからでも右クリックからでもフォルダに書き、最初の曲とプレビューを開く。知らせに
  「Reveal Folder」と、報告があれば「Show Details」（曲ごとの報告を出力チャンネルへ）。
- LSP: `lilysharp/importMusicXml` の応答に `Pieces`（名前・曲名・`.lys`・報告・エラー）。1 曲のときは今までどおり `Lys` だけ。
- `MusicXmlImporter.ImportBytes`（1 つの `.lys` を返す古い入口）は最初の曲を読み、何曲あったかを報告に書く。

## 4. 読まないもの（報告して落とす）

- `P:` の部分の順番・`W:`（曲の後の歌詞）・`s:`（記号の行）・`U:` `m:`（利用者の定義・マクロ）・
  バグパイプの調（`K:HP`）・`K:` の後に足した臨時記号（`K:D =c`）は報告して効かせない。
- 楽譜の改行（ABC は行の終わりで段を改めることが多い）は写さない＝Lily# の自動の段組み。
- セーニョ・コーダ（`S` `O`）・`!D.C.!` などの道順は報告して落とす。
