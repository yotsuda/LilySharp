# A-B リピート（設計メモ）

オーナーの要望と決定（2026-11-16〜17・第1286）。Transcribe! の A-B リピートと区間の保存を手本に、プレビューで練習の範囲を決めて鳴らす。

## 1. 決まったこと

- **記号は A と B の旗**。A の旗は右（範囲の内側）、B の旗は左を向く。小節線の上にだけ置ける。色は再生中の小節（青）・選択と別の色。A と B の間を薄く着色する。
- **ボタンは 2 つ**: `A-B`（範囲を A から B にする）と `繰り返し`（今の Loop の On／Off を独立させたもの）。
  | A-B | 繰り返し | 動き |
  |---|---|---|
  | オフ | オフ | 曲全体を 1 回 |
  | オフ | オン | 曲全体を繰り返す（`|: :|`・D.S. を含む演奏順のまま） |
  | オン | オフ | A から B まで 1 回で止まる |
  | オン | オン | A から B までを繰り返す |
- **範囲は刷ってある小節番号**。B はその小節を含む（13〜16 なら 4 小節）。旗で置いても数値で入れても同じ。
  繰り返し記号の中に置いた範囲は**刷ってある順に 1 回ずつ**通す（範囲の中の `:|` や D.S.／Coda の飛び先には従わない）。form で同じ section を 2 回演奏する曲は 2 回刷られ、別の小節番号を持つので、何回目かも番号で選べる。
- **最初の位置**: A-B を押したとき旗が無ければ、エディタのキャレットの小節を A、その 4 小節後までを B。範囲を選択していれば、その最初の小節から最後の小節まで。
  **今の「エディタで選んだ範囲をループ」は廃止**し、この入口に置き換える。
- **旗のドラッグ**: 旗は常にどこかの小節線の上にいる。マウスが閾値（隣の小節線までの半分）を超えたら、旗がすっと隣の小節線へ動いてぴたっと付く。
  つかんでいる間は、旗を太い縁取り・少し大きく、カーソルを「つかむ手」にし、旗からマウスまで点線の引っ張り線と半透明の小さな旗を出す（旗がまだ動いていなくても何を引っ張っているかが分かる）。移る瞬間、移る先の小節線を一瞬強調する。
- **旗の入れ替え**（オーナー要望 2026-11-17・第1287）: つかんだ旗はもう片方の旗を越えて動かせる。越えた瞬間に A と B が入れ替わり（つかんでいる旗が B になる・もう片方は同じ小節線のまま A になる）、範囲は 2 本の旗の間の小節。旗は小節線に立つ（線 L＝小節 L の前＝小節 L−1 の後・A は線 abFrom、B は線 abTo+1）。2 本が同じ線には立たない（0 小節にならない）。ドラッグ中の行き先は、まずポインタに近い段を選び、その段の中で横に一番近い小節線（縦横を混ぜた距離では、縮小時に隣の段の線を拾って行き来した）。
- **右クリック**: 小節線に「ここを A に」「ここを B に」、section の見出しに「この section を A-B に」。
- **区間の帯（8 本）**: Practice の下に常に並べる。1 本が曲全体の長さで、色の部分がその区間。
  帯をクリック＝その区間を呼び出す（旗が移り A-B で鳴る）。**Shift＋クリック＝今の A-B をその帯に保存**（上書き）。名前は任意（ダブルクリックでその場で入力・付けなければ「13–16」）。
  **旗で決めた A-B はその場限り**（保存しない）。帯の区間はファイルごとに **VS Code の作業領域**に保存（JSON で持ち、後で `.dettato.json` に移せる形）。
- **ループ中に `.lys` を直したら、次の周から新しい音で鳴らす**（耳コピで 1 小節を回しながら直す使い方）。今の周は最後まで鳴らす。間に合わなければもう 1 周前の音で、間に合った周から切り替える。範囲は小節番号のまま。

## 2. 作り

- **刷られた小節の番号を音符に**: `MidiExporter` は曲を刷ってある順に一度歩いてから演奏順に展開する（`PlayedTimeline.Unfold`）。展開の前に、各音符へ刷られた小節の番号（`MidiNote.PrintedBar`＝その時点の `BarTicks` で数えた小節の番号・弱起は 0）を付ける。展開でも音符と一緒に動く。LSP の `PlaybackNote.M`。
- **範囲の取り出し**: `playSpanWindow` に「範囲の判定」を渡す口を足し、A-B は `M` が [A, B] の音で窓を決める。1 回ずつ通す（`once`）ので、窓の中の繰り返しの 2 回目と範囲外の小節は落として時間を詰める（今のループと同じ仕組み）。
- **小節番号と小節の位置**: プレビューの SVG の小節の箱（`bar-box`・`bar-staff`）に刷られた小節の番号（measure index）を持たせ、旗の位置・数値の欄・キャレットの小節をそこから読む。

3. 楽譜上の旗（吸い付いて移るドラッグと、つかんでいる旗の見せ方）。
4. 小節線と section の見出しの右クリック。
5. 8 本の区間の帯と作業領域への保存。

### 5 の実際の形（第1287）

- 帯は練習メニューの一番下の行「Ranges」に 8 本、縦に並ぶ。空の帯は破線で番号だけ。色はメニューのボタンと同じ自前の明るい配色（VS Code のテーマ色ではない）、範囲は旗と同じオレンジ。今の A-B と同じ範囲の帯はオレンジの縁。
- クリック＝呼び出し（A-B オン・旗が移る・鳴っていれば新しい範囲の頭から）。Shift＋クリック＝今の A-B をその帯に（A-B オフなら何もしないで一言）。ダブルクリック＝その場で名前（空なら小節番号）。**Alt＋クリック＝空に戻す**（決定にはなかった。消す手段が無いと 8 本が埋まった後に困るので足した）。
- 保存は拡張の `workspaceState`、鍵は `lilysharp.abRanges:<ファイルの絶対パスの小文字>`（ディスクに無いファイルは URI）。値は 8 要素の配列 `{ from, to, fromBar, toBar, name? } | null`＝`from`／`to` は刷られた小節の番号（measure index・0 から）、`fromBar`／`toBar` は保存したときに刷られていた小節番号（JSON を読む人と、後で `.dettato.json` へ移すとき用。ページは `from`／`to` で動く）。全部空なら鍵ごと消す。
- 拡張は描くたびに `{ type: 'abRanges', chart, ranges }` をページへ送り（別のファイルに切り替わればその本の 8 本）、ページは変えるたびに同じ形で送り返す。正規化・表示名・帯の位置は `abRangesCore.ts`（拡張とページの bundle `LysSynth` の両方が使う・網 `abRanges.test.ts`）。
- 楽譜が短くなって範囲の頭が無くなった帯は呼び出せない（「The score has no bar N now」）。範囲の尾だけはみ出す帯は曲の終わりまで塗り、呼び出すと B は最後の小節。
- ファイルの名前の変更・コピーには付いて行かない（要るなら録音の `followRenames`・`followCopies` と同じ形で足す）。

## 3.5 鳴らしながら旗を動かす（オーナー報告 2026-11-17・第1288 で直した）

- **録音と一緒の A-B は B で止まる**: Repeat オフで録音が楽譜と鳴るとき、再生の終わりを録音の最後にしていた（曲全体を鳴らすときの規則）＝楽譜の音は B で終わるのに録音は曲の終わりまで鳴り、その間ハイライトも消えた。範囲を鳴らすときは範囲の終わり（`startRecordingAlong` が `loopRound` を返す）。
- **最後の頼みの返事だけを鳴らす**: 旗を離すたびに鳴らし直しを頼む（`replayIfPlaying` → `requestPlayback`）。頼みが 2 つ重なると、1 つ目の返事が A-B の範囲（`pendingSpan`）を使って空にし、2 つ目の返事は範囲なしの再生として曲の頭から全体を鳴らした。頼みに番号を付け（`requestPlay`・`playSeq`）、拡張が返事に同じ番号を付けて返し、ページは最後の番号の返事だけを使う。試聴の返事は古くても試聴に回す（`auditionSeq`）。
- 実物の VS Code（Lab `p1288/e2e/cdp-abrec.mjs`・録音つきの 4 小節・A-B 2〜3 小節）: 直す前は録音が B の後も 11.9 秒まで鳴り、頼みを 2 つ重ねると小節 0 から全体が鳴った。直した後はどちらも 2〜3 小節で止まる。
