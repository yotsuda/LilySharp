# 声部進行の検査（Voice-leading check）— 設計案（第1031・2026-10-28）

`docs/ROADMAP.md` の提案（2026-10-25）「四声体（SATB）の連続 5 度・8 度、声部の交差、声部の間隔の
開きすぎに警告を出す — 教会の聖歌隊と合唱の編曲のため」の設計。**§7 の 3 点は 2026-10-28 に決まった**
（宣言は汎用の検査の pragma `check`・宣言したら常時・情報の強さ）。

## 0. 原則

1. **規則は様式のもので、誤りではない。** 連続 5 度はポップスでもロックでも普通に書く。四声体の和声を
   書く人にだけ出す（§2）。強さは「情報」（LYS5004 と同じ青）を案とする（§7 C）。
2. **書き方を問わない。** 合唱譜は 3 つの書き方で書かれる（§1）。どれで書いても同じ答えを出す。
3. **鳴る音で判定する。** 音高は再生と同じ（`MidiExporter` の音）。移調楽器・`octave N`・`pitch` に
   左右されない。テノールの `treble_8` も鳴る高さで比べる。
4. **指すのは楽譜の音符。** 波線は 2 つ目の響きの、関わる 2 声の音符に付ける。メッセージは 2 声の名前と
   音程を言う（「soprano と bass が 5 度から 5 度へ: G4/C4 → A4/D4」）。

## 1. 声部の見分け方（3 つの書き方）

| 書き方 | 例 | 声の取り出し |
|---|---|---|
| ⒜ 1 声 1 パート | `part s { instrument soprano }` … `voice-bass`、または `choirStaff` に 4 段 | パートがそのまま 1 声 |
| ⒝ 2 段に 2 声ずつ（聖歌集の形） | `part upper { section A { voice { e'4 … } { c'4 … } } }` | `voice { } { }` の枝ごとに 1 声（上の枝が上声） |
| ⒞ 和音で 2 声 | `part upper { <c' e'>4 <d' f'> }` | 和音の音を下から並べて、上を上声・下を下声 |

土台は揃っている: `MidiNote` は `Part`・`SourcePos`（書かれた位置）・`StartTick` を持つ。⒝ は
`SourcePos` から構文をたどって `voice` のどの枝かを読む。⒞ は同じ位置から出た音を高さで並べる。
声の数は 4 に限らない（3 声・5 声でも同じ規則で 2 声ずつ比べる）。

## 2. いつ出すか

- **案 B1（推奨）: 宣言したときだけ常時診断。** 楽譜に「この曲は四声体」と書いたら、打つたびに
  波線が出る。書き方は §7 A。
- 案 B2: コマンドだけ（*Lily#: Check Voice Leading*）。押したときに一覧（問題パネル）に出て、
  打っている間は出ない。
- 案 B3: 自動。声の preset が 4 つ揃うか `choirStaff` に 4 段あれば出す。宣言は要らないが、
  四声体の和声でない合唱曲（ポップスの合唱編曲）にも出てしまう。

## 3. 規則（初版）

| 規則 | 中身 | 初版 |
|---|---|---|
| 連続 5 度・連続 8 度 | 同じ 2 声が完全 5 度（または 8 度・同度、オクターブ違いを含む）から、両方とも動いて、また同じ完全音程へ。反行（5 度→12 度）も含む | 入れる |
| 声部の交差 | 下の声が上の声より高い | 入れる |
| 間隔の開きすぎ | 隣り合う上 3 声（S–A・A–T）が 8 度より広い。T–B は 12 度まで | 入れる |
| 声部の超越（overlap） | 下の声が、上の声の直前の音より高く進む | 次段 |
| 隠伏 5 度・8 度 | 外声（S–B）が並行して完全音程に入り、ソプラノが跳躍 | 次段 |
| 導音の解決・増音程の進行 | 調と和声の読みが要る（和声の分析の部品を使う） | 範囲外 |

**音域は足さない**: 声の preset の音域外は既に LYS1052 が言う。

## 4. どの時点を比べるか

- **響き**: どれかの声が新しく鳴り始めた時点ごとの縦の並び（各声のその時点で鳴っている音）。
- **連続**: 隣り合う 2 つの響きで、比べる 2 声が両方とも音高を変えたとき。片方が保っている（タイ・
  長い音）なら連続にしない。
- **休符**は線を切る（休符をまたいだ 2 音は比べない）。経過音・刺繍音の扱い（強拍だけを比べるか）は
  初版では区別せず、すべての響きを比べる（教本の多くと同じ。誤検出が多ければ次段で拍を見る）。
- 反復記号・form は再生の順（MIDI）で並ぶので、`form` の繰り返しの継ぎ目も比べる。

## 5. 作り

- **核**: `LilySharp.Core/Semantics/VoiceLeading.cs`（仮）。入力は `MidiExporter` の音と構文木、出力は
  （規則・2 声・2 つの響きの位置・音名）。§1 の 3 つの書き方を同じ声の列にしてから §3 の規則を当てる。
- **出口**: §2 で決まる。B1 なら意味の検査（`SemanticValidation`）に 1 つ足す。ただし MIDI を組むので、
  打鍵ごとの費用を測ってから入れる（CLAUDE-OPERATIONS §2: 計測はユーザーに一声かけて）。B2 なら
  LSP の要求 1 つと拡張のコマンド。
- **コード**: 新しい族を 1 つ（LYS 番号は実装時に空きを確かめて決める）。
- **網**: 規則ごとに「出る形・出ない形」（反行の連続 5 度は出る・片方が保つと出ない・休符をまたぐと
  出ない・交差・間隔）を ⒜⒝⒞ の 3 つの書き方で。聖歌集の実例（パブリックドメインのコラール 1 曲）で
  誤検出を数える。

## 7. 決めたこと・決めてほしいこと

- **B. いつ出すか＝B1（宣言したら常時）**（オーナー決定 2026-10-28）。
- **C. 強さ＝情報（青）**（オーナー決定 2026-10-28）。
- **A. 宣言の書き方＝汎用の検査の pragma `check`**（オーナー決定 2026-10-28:「pragma であることが
  わかりやすい方が良いし、一般化しておけば後でほかの拡張もしやすくなる」）。下の A3 を一般化した形:

  ```
  CheckDecl = 'check' , CheckRule , { Identifier } ;   (* top level, any number, anywhere *)
  CheckRule = 'voiceLeading' ;                          (* later: 'pageTurns', … *)
  ```

  `check voiceLeading s a t b` — 引数は声部のパート名を**上から順に**（2 つ以上）。⒝ の書き方
  （2 段に 2 声ずつ）は `check voiceLeading upper lower` で、各パートの中は `voice` の枝の順。
  出力（描画・再生・書き出し）は変えない＝lint の有効化（C# の `#pragma warning`、Rust の `#![warn]`）。
  エラー: 知らない規則名（規則の一覧を言う）・宣言されていないパート・同じパートを 2 度・2 つ未満。
  補完は `check` → 規則名 → パート名。ホバーは規則の中身。

  以下は決定前の比較（記録）。宣言が答えなければならないのは「どのパートが声部で、上から何番目か」
  （ピアノ伴奏は比べない・ソプラノとアルトの交差は順番が分からないと言えない）。候補 3 つ:

| 案 | 書き方 | 良いところ | 悪いところ |
|---|---|---|---|
| A1 layout のスイッチ | `layout { voiceLeading true }` | 文法の形が既にある（`Boolean` の項目・補完とホバーの型どおり）。1 行で済む | `layout` は紙面の見た目の設定で、検査は見た目ではない。どのパートが声部かを言わない＝声の preset や `choirStaff` から推し量るしかなく、ピアノ伴奏付きでは推し量りが外れうる。名前付きの layout を score が選ぶ仕組みとも噛み合わない |
| A2 score の組に `as chorale` | `choirStaff { staff s  staff a  staff t  staff b } as chorale` | 声部と順番が組の段の並び（上から）でそのまま決まる。伴奏は組の外なので入らない。⒝（2 段に 2 声ずつ）も段の中の枝の順で自然に読める | 新しい文法（今の `StaffGroupBody` は `as` を取らない）。score は「何を刷るか」の宣言で、検査を混ぜる。score が複数ある本では、どの score の組を見るかの規則が要る（既定の score の組・同じ音楽は 1 回だけ検査） |
| A3 最上位の文で声部を名指す | `voiceLeading s a t b`（上から順に） | 検査だと一目で分かる。声部と順番を書き手が直接言う＝推し量りなし。score に依らない。⒝ は `voiceLeading upper lower` で枝の順に読む | 最上位の語が 1 つ増える（補完・ホバー・GRAMMAR に足す）。パート名を 2 か所に書く（パート宣言と並び） |

  **推奨は A3**: 「どれが声部で何番目か」を推し量らずに済むのは A2 と A3 だけで、A3 は文法の追加が
  最上位の 1 文に閉じ、score の仕組みに触れない。A2 は合唱譜を `choirStaff` で書く人には二度書きが
  無い分だけ簡潔。
