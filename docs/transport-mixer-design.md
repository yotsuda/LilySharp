# 再生の操作とミキサーの整理（設計メモ）

オーナーの要望（2026-11-17・第1289）:「機能的には、かなり良くなってきた。UI を整理する必要がある。ミキサーのような機能をひとつに統合するべき。レコーディングは、すべてをまとめてオフにしたり、すべてをまとめてオンにしたりできるようにしたい。lys テキストのパートも同じように操作できるようにしたい。再生の機能も、今はポーズボタンがないし、楽器演奏の練習者が練習に使いやすいように操作できるようにしたい。」

## 1. オーナー決定（2026-11-17）

1. **ミキサーと練習を別のパネルにする**。ツールバーに「ミキサー」と「練習」の 2 つのボタン。録音パネルはミキサーの録音のグループに吸収して消す。
   ```
   ミキサー
    ▼楽譜   [全部 On/Off] ━━●━━
      bass         [M][S] ━━●━━
      harmony      [M][S] ━━●━━
    ▼録音   [全部 On/Off] ━━●━━
      drums        [M][S] ━━●━━
      bass         [M][S] ━━●━━
      other/vocals [M][S] ━━●━━
      ▸速度・高さ（畳む）

   練習
    Tempo ━━●━━ 100%
    Metronome / Count-in
    A-B [5]-[8]  Repeat
    Ranges ░░▓░░
   ```
2. **ミキサーの各行はミュート・ソロ・フェーダー**。グループの見出しに一括のオン・オフとまとめての音量。
3. **再生の操作は Transcribe! の形**（再生・一時停止・停止の 3 つ）。
   - **再生の開始位置は A の旗**（オーナーの提案）。**A の旗は常に表示**し、既定は曲の頭。**A-B を有効にしたら B の旗**（と範囲の着色）も出す。
   - **▶ 再生**: いつ押しても A から鳴らす（鳴っている途中でも、一時停止中でも）。A-B が有効なら A から B まで。
   - **⏸ 一時停止**: 鳴っているときはその場で止める。一時停止中にもう一度押すと、止めた所から続ける。A は動かない。
   - **■ 停止**: 止めて、表示を A に戻す。
   - **エディタのキャレットは再生の開始位置に関係させない**（オーナー:「エディタのキャレットは頻繁に操作するし、必ず編集位置から再生したいとは限らない。ユーザーは『なぜここから再生されちゃうのか』と思うことが多いだろう」）。**プレビューで楽譜上の小節をクリックしたら、そこを A にする**。
4. **周ごとのカウントイン**: Count-in が有効なら、Repeat で回るたびに各周の前に 1 小節のクリック（オーナー:「周の間に休みを入れるのは、カウントしてから再生を有効にすれば、周ごとにカウントを再生してから再生すれば良い」）。

## 2. Claude が決めた細部（オーナーに伝えた・違えば直す）

- A-B 有効で B より後ろの小節をクリックしたら、A と B の間の小節数を保ったまま B も動かす（範囲を持ち運ぶ）。
- スペースキー（プレビューにフォーカスがあるとき）: 止まっているときは ▶、鳴っているときと一時停止中は ⏸。
- 鳴らしながら旗を動かしたとき・Repeat を切り替えたときに今の位置から続ける動き（`docs/ab-repeat-design.md` §3.5）は残す。▶ を押したときだけ A から。
- キャレットから鳴らす明示の操作（右クリックの「ここから再生」、キャレットの音を鳴らすキー）は残す（「ここから」と頼む操作なので、開始位置の規則とは別）。

## 3. 段取り

| 段 | 中身 |

## 4. 段 1 の実際の形（第1289）

- **一時停止**: `paused`（鳴らしていた一覧・位置・始まり・ループの周、録音だけなら録音の秒）を覚えて止め、⏸ でそこから `startPlayback`。「鳴っているか」は `playingNow()`（■ が押せる＝一時停止中も押せるので、■ の状態を目印にしていた 10 か所を置き換えた）。ホストへの再生中の知らせは、言った状態を覚えて変わったときだけ（`playStateSaid`）。
- **A の小節から鳴らす**: `pendingStartBar`（A の刷られた小節）を返事の受け取りで `barStartIn`＝その小節が最初に鳴る最初の出来事（音符・休符の光）をその前の小節線へ戻した時刻、から鳴らす。止まっているときのヘッダの時刻も同じ計算（手元の音符が無ければ小節の `data-start` をホストに訊く）。
- **A の旗は常に**: `drawAbFlags` が A-B オフでも A を描き、B と着色は A-B オンだけ。`setA(m, replay)`＝小節のクリック（音符のクリックもその小節へ）・右クリックの A Here・A-B オフでのドラッグ。A-B オンで B より後ろなら B も同じ間隔で動く。A-B オフで B より後ろへ動かしたら B は忘れ、次に A-B をオンにしたとき A から 4 小節で置き直す（`abFirstPlace`）。
- **スペースキー**: プレビューにフォーカスがあり、入力欄でないとき。止まっていれば ▶、鳴っている・一時停止中なら ⏸。
- 実物の VS Code（CDP・Lab `p1289/e2e/cdp-transport.mjs`・オーナーの My Life の写し）で上の全部。
- **巻き戻し**（オーナー要望 2026-11-17）: ⏮ で A の旗を頭へ（A-B オンでも B はそのまま）。鳴っていれば頭から鳴らし直し、一時停止中なら止めて頭。
- **楽譜の音を全部オフにしても小節が光る**（オーナー要望 2026-11-17）: オフにしたパートの音符を一覧から落とさず `Z` の印で残す（`practiced` が常に `keepSilent`）。音にする所（`startPlayback` の `played`、歌い手の割り付け）は `Z` を飛ばし、ハイライトは `Z` の音符を光らせず、鳴る音符が無いときだけ `Z` の音符から小節を光らせて表示も付いて行く（`quietCursor`）。実物の VS Code で、bass をオフに録音だけで鳴らして小節が 1→2→3 と移るのを確かめた（Lab `p1289/e2e/cdp-quiet.mjs`）。
- **▶ で画面を A の旗へ**（オーナー要望 2026-11-17）: ▶ を押した瞬間に旗が画面の上端から 30 px に来るよう動かし（`showAFlag`・ページ自身のスクロール＝`follow.auto`）、その後はいつもの付いて行き。先読みのスクロールはオフのパートの音符も使う（光らせはしない）。実物の VS Code で、41 小節目の A へ移り鳴っている小節がずっと画面の中（Lab `p1289/e2e/cdp-follow.mjs`）。
- 残る穴: 一時停止中に Repeat やパートを変えても、再開は止めたときの一覧のまま（次の ▶ から効く）。
