# 再生の操作とミキサーの整理（設計メモ）

オーナーの要望（2026-11-17・第1289）:「機能的には、かなり良くなってきた。UI を整理する必要がある。ミキサーのような機能をひとつに統合するべき。レコーディングは、すべてをまとめてオフにしたり、すべてをまとめてオンにしたりできるようにしたい。lys テキストのパートも同じように操作できるようにしたい。再生の機能も、今はポーズボタンがないし、楽器演奏の練習者が練習に使いやすいように操作できるようにしたい。」

## 1. オーナー決定（2026-11-17）

1. **ミキサーと練習を別のパネルにする**。ツールバーに「ミキサー」と「練習」の 2 つのボタン。録音パネルはミキサーの録音のグループに吸収して消す。
   ```
   ミキサー
    ▼楽譜   [全部 On/Off] ━━●━━
      bass         [M][S] ━━●━━
      harmony      [M][S] ━━●━━
    ▼録音   [全部 On/Off] ━━●━━
      drums        [M][S] ━━●━━
      bass         [M][S] ━━●━━
      other/vocals [M][S] ━━●━━
      ▸速度・高さ（畳む）

   練習
    Tempo ━━●━━ 100%
    Metronome / Count-in
    A-B [5]-[8]  Repeat
    Ranges ░░▓░░
   ```
2. **ミキサーの各行はミュート・ソロ・フェーダー**。グループの見出しに一括のオン・オフとまとめての音量。
3. **再生の操作は Transcribe! の形**（再生・一時停止・停止の 3 つ）。
   - **再生の開始位置は A の旗**（オーナーの提案）。**A の旗は常に表示**し、既定は曲の頭。**A-B を有効にしたら B の旗**（と範囲の着色）も出す。
   - **▶ 再生**: いつ押しても A から鳴らす（鳴っている途中でも、一時停止中でも）。A-B が有効なら A から B まで。
   - **⏸ 一時停止**: 鳴っているときはその場で止める。一時停止中にもう一度押すと、止めた所から続ける。A は動かない。
   - **■ 停止**: 止めて、表示を A に戻す。
   - **エディタのキャレットは再生の開始位置に関係させない**（オーナー:「エディタのキャレットは頻繁に操作するし、必ず編集位置から再生したいとは限らない。ユーザーは『なぜここから再生されちゃうのか』と思うことが多いだろう」）。**プレビューで楽譜上の小節をクリックしたら、そこを A にする**。
4. **周ごとのカウントイン**: Count-in が有効なら、Repeat で回るたびに各周の前に 1 小節のクリック（オーナー:「周の間に休みを入れるのは、カウントしてから再生を有効にすれば、周ごとにカウントを再生してから再生すれば良い」）。

## 2. Claude が決めた細部（オーナーに伝えた・違えば直す）

- A-B 有効で B より後ろの小節をクリックしたら、A はクリックした小節・B はその後ろ＝その 1 小節（オーナーの報告 2026-11-17「M10〜M11 を選んで M21 をクリックすると、B は M21 の終わりなのに A は M21 の上の段の小節に動く」＝旗のドラッグと同じく入れ替えていたので A は古い B の M11 へ行った。その前は範囲を持ち運んでいて「M5〜M8 で M9 をクリックしたら M9〜M12 になった、変だ」）。小節・音符のクリックは鳴らしている途中なら旗を動かしたときと同じく鳴らし直す（`setA(m)`＝`replayIfPlaying`）。A-B オンのときはクリックした所への頭出し（`seekToCopy`＝曲全体の一覧で飛ぶので B を越えた）はしない。
- スペースキー（プレビューにフォーカスがあるとき）: 止まっているときは ▶、鳴っているときと一時停止中は ⏸。
- 鳴らしながら旗を動かしたとき・Repeat を切り替えたときに今の位置から続ける動き（`docs/ab-repeat-design.md` §3.5）は残す。▶ を押したときだけ A から。
- キャレットから鳴らす明示の操作（右クリックの「ここから再生」、キャレットの音を鳴らすキー）は残す（「ここから」と頼む操作なので、開始位置の規則とは別）。

## 4. 段 1 の実際の形（第1289）

- **一時停止**: `paused`（鳴らしていた一覧・位置・始まり・ループの周、録音だけなら録音の秒）を覚えて止め、⏸ でそこから `startPlayback`。「鳴っているか」は `playingNow()`（■ が押せる＝一時停止中も押せるので、■ の状態を目印にしていた 10 か所を置き換えた）。ホストへの再生中の知らせは、言った状態を覚えて変わったときだけ（`playStateSaid`）。
- **A の小節から鳴らす**: `pendingStartBar`（A の刷られた小節）を返事の受け取りで `barStartIn`＝その小節が最初に鳴る最初の出来事（音符・休符の光）をその前の小節線へ戻した時刻、から鳴らす。止まっているときのヘッダの時刻も同じ計算（手元の音符が無ければ小節の `data-start` をホストに訊く）。
- **A の旗は常に**: `drawAbFlags` が A-B オフでも A を描き、B と着色は A-B オンだけ。`setA(m, replay)`＝小節のクリック（音符のクリックもその小節へ）・右クリックの A Here・A-B オフでのドラッグ。A-B オンで B より後ろなら B も同じ間隔で動く。A-B オフで B より後ろへ動かしたら B は忘れ、次に A-B をオンにしたとき A から 4 小節で置き直す（`abFirstPlace`）。
- **スペースキー**: プレビューにフォーカスがあり、入力欄でないとき。止まっていれば ▶、鳴っている・一時停止中なら ⏸。
- 実物の VS Code（CDP・Lab `p1289/e2e/cdp-transport.mjs`・オーナーの My Life の写し）で上の全部。
- **巻き戻し**（オーナー要望 2026-11-17）: ⏮ で A の旗を頭へ（A-B オンでも B はそのまま）。鳴っていれば頭から鳴らし直し、一時停止中なら止めて頭。
- **楽譜の音を全部オフにしても小節が光る**（オーナー要望 2026-11-17）: オフにしたパートの音符を一覧から落とさず `Z` の印で残す（`practiced` が常に `keepSilent`）。音にする所（`startPlayback` の `played`、歌い手の割り付け）は `Z` を飛ばし、ハイライトは `Z` の音符を光らせず、鳴る音符が無いときだけ `Z` の音符から小節を光らせて表示も付いて行く（`quietCursor`）。実物の VS Code で、bass をオフに録音だけで鳴らして小節が 1→2→3 と移るのを確かめた（Lab `p1289/e2e/cdp-quiet.mjs`）。
- **▶ で画面を A の旗へ**（オーナー要望 2026-11-17）: ▶ を押した瞬間に旗が画面の上端から 30 px に来るよう動かし（`showAFlag`・ページ自身のスクロール＝`follow.auto`）、その後はいつもの付いて行き。先読みのスクロールはオフのパートの音符も使う（光らせはしない）。実物の VS Code で、41 小節目の A へ移り鳴っている小節がずっと画面の中（Lab `p1289/e2e/cdp-follow.mjs`）。
- 残る穴: 一時停止中に Repeat やパートを変えても、再開は止めたときの一覧のまま（次の ▶ から効く）。
- **直し（第1290・オーナーの報告「止めて楽譜をクリックして A を動かし ▶ を押すと、頭から鳴ることがある」）**: Repeat オン・A-B オフの ▶ は「全体をぐるぐる」の経路で、一覧を頭から並べて A を見ていなかった（Repeat オフの経路だけが `pendingStartBar` を読んでいた）。今は最初の周を A の小節から（Count-in オンなら A の小節のカウントをその前に）、2 周目からは頭から。一覧は周の時刻のまま（`fromOffset(rounds, entry)` とカウントのクリックを足し、その手前から鳴らす）、`loopEntry` が最初の周の音楽の入りで、それまでヘッダは A（`placeNow`）、声は A より前を歌わない（`voicePlan.entry`）。一時停止も持ち越す。実物の VS Code で、録音のオン・オフ × Repeat × Count-in × A を 2 か所、直す前は Repeat オンの全部が小節 0 から、直した後は全部 A の小節から（Lab `p1290/e2e/cdp-astart.mjs`・`cdp-astart-{before,after}.log`）。
- **直し（第1290・オーナー「小さな点も直して」）**: Repeat オフで Count-in のとき、カウントの間ヘッダが A の手前の時刻から進んでいた（音楽が A から入る一覧で、時刻からカウントを引いただけだった）。A から鳴らす ▶ と A-B 1 回の ▶ も、カウントの後に音楽が入る一覧の時刻を `loopEntry` に置き、`placeNow` と `playbackScoreSeconds` はそこまで A を示す（旗やテンポを動かしたときの作り直しも A から）。実機で、カウント中のヘッダが A（4・2 s、直す前は 3.07・0.35・2.75・0.75 s）、音楽に入ってからは進むこと（Lab `cdp-astart-after2.log`）。

## 5. 段 2 の実際の形（第1289）

- **ミキサーのパネル**は録音のパネル（`recPanel`）を作り替えたもの（id・ドラッグ・前に出す仕組みはそのまま）。ツールバーのボタン（`recPanelBtn`）は録音の有無に関係なく常に出し、録音が無いときは録音のグループ（`#mixRecGroup`）だけを隠す。押し込まれた表示は「ミキサーで何か変えてある」とき（`showMixerHead`）。練習のボタンの押し込みは Tempo・Metronome・Count-in・Repeat・A-B だけ。
- **リセット**（オーナー 2026-11-17「Reset parts にもう少し良いキャプションを・ホバーのヘルプも長すぎる」）: **As scored**（ヘルプ "The parts the selected score plays"）＝楽譜のグループだけを、選んでいる score が鳴らすパートに戻す（録音のパートには触らない＝録音は自分のボタンで）。**Faders 100%**（"Every fader to 100%"）＝楽譜と録音の全部のフェーダーとグループのフェーダーを 100% に。両方のグループに効くのでミキサーの一番下（`.mfoot`）。
- **楽譜のグループ**: 見出しに All（どれか鳴っていれば押し込み。外すと全部オフ、押し込むと楽譜のパートと声が全部オン）と、グループのフェーダー（`scoreLevel`・0〜200%・ダブルクリックで 100%）。各行は名前（押し込み＝鳴る、押すとミュート・従来の動き）・S・フェーダー。M のボタンは名前と同じなので置かない（オーナー決定 2026-11-17）。リセットは下の項。パートの一覧の取り寄せ（`requestParts`）はミキサーを開いたときに。
- **見出しのボタンは 2 つ（オーナー要望 2026-11-18）**: グループのオン／オフ（楽譜は **On**＝`scoreOn`、録音はファイル名のボタン＝`recOn`）と **All**。オン／オフは各行の自分のオン／オフを変えない＝外すとグループ全体が黙り、押し込むと行でオンにしてあったものだけが鳴る（黙っている間、行は押し込みのまま薄く表示）。All は行のオン／オフを全部書き換える（どれかオンなら全部オフ、全部オフなら全部オン）。録音の All はパートがあるときだけ出る。楽譜のオフは `eff()` が全パート・全声を黙らせて作る（`practice` は触らない＝書き出しも同じ）。ソロの行はグループがオフでも鳴る。As scored は `scoreOn` も戻す。2026-11-17 の「録音がオフのときにパートを押すと録音がオンになり、そのパートだけ鳴る」はやめた（パートの行は自分のオン／オフだけ）。
- **録音のグループ**: 見出しは録音のファイル名のボタン（従来の `recOnBtn`。情報が多いほうが良いのでファイル名のまま＝オーナー 2026-11-17）・音量。グループ全体の S は置かない（もう一方のグループの All を外せば同じ＝オーナー決定 2026-11-17）。**楽譜の All と録音のボタンはどちらも「押し込む＝そのグループの全パートをオン、外す＝全パートをオフ」**（オーナー決定 2026-11-17）。押し込みの表示はどれかのパートが鳴っているとき（楽譜は `showMixerHead`、録音は `recAllOn()`＝録音がオンでどれかのパートがオン）。録音を外すと `recOn` を切って `recPartsOff` を全パートに、押し込むと `recOn` を入れて全パートをオン。録音がオフの間は各行も M が点いて見え、その行の M を外すと録音がオンになってそのパートだけが鳴る。楽譜の All を押し込んでも、楽譜が最初からオフにしている extra はそのまま（戻すのは Reset parts）。その下に録音のパートの行（名前・S・フェーダー）。速度・高さの設定は畳める「Speed and pitch」（`<details>`）に収めた。練習パネルの Parts の一覧から Recording の行と録音のパートは外した。
- **ソロ**: `solo`（`part:名`・`voice:鍵`・`rec:名`）。どれかがソロなら、ソロでない行は鳴らない。鳴る中身は `eff()`＝練習の状態にソロとグループのフェーダーを当てた写し（ソロでないパートを `muted` へ・声を `voicesOff` へ、extra・楽器・声のオンを絞る、各行の音量に `scoreLevel` を掛ける）。読む所（`practiced`・声の選び・楽器を鳴らすかの判断・書き出しへ送る `practiceState`）を `eff()` に替えた。行の表示は自分の状態のまま（ソロで黙っている行は薄く＝`unheard`）。録音は `recLevel()` がソロ中で録音のどれもソロでなければ 0、`recPartMix()` が録音のパートのソロ中にソロでないパートを 0。ソロとグループのフェーダーは覚えない（開き直すと解ける）。**S は「この行を聴く」**（オーナー決定 2026-11-17 第1290）: ソロの行は自分のミュート・グループの All が外れていても鳴る（`eff()` がソロの行を `muted`・`voicesOff` から外し、score が鳴らさない extra なら `extraOn` に足す。録音は `recordingAlong()` が録音のボタンが外れていても録音のパートのソロで真、`recPartMix()` がソロのパートをオフでも鳴らす）。ミュートの設定は書き換えない＝S を外せば元に戻る。それまではミュートがソロに勝ち、All を外したグループの行は S を押しても黙っていた（オーナーの指摘）。
- 実物の VS Code（CDP・Lab `p1289/e2e/cdp-mixer.mjs`・4 小節の録音つきの譜面）で、All のオフ・オン、録音の bass のソロ（録音のほかのパートと楽譜が 0）、楽譜のフェーダー 50%（harmony の音量 0.5）、録音の vocals のミュート、行とフェーダーの左端が見出しと揃うこと、を確かめた。× が `float` なので、グループに `clear: both`（最初の見出しが × に回り込んで狭くならないように）。

## 6. 1 つのパネル（第1289・段 3 の前半）

オーナー（2026-11-17）:「練習ウィンドウとフェーダーウィンドウが分かれているけど、同じウィンドウにすべき。各グループを展開・省略可能にすれば、必要なボタンがすべてのっているウィンドウが作れる」。VS Code の別のペインに出す案も挙がったが、音・状態・ハイライトがプレビューのページの中にあり、別ページにすると全操作を拡張機能の本体経由で中継し状態を二重に持つことになるので採らない（Claude の判断・オーナー了承）。楽譜を隠さないことが要るなら、後でページの中でパネルを右端に固定する切り替えを足す。

- ツールバーのボタンは練習のボタン 1 つ（「Practice and mixer」）。ミキサーのボタンとパネル（`recPanelBtn`・`recClose`）は消し、JS の `recPanel` は `practicePanel` を指す。ボタンの押し込みは練習の変更（`practiceOn`）かミキサーの変更（`mixerChanged`）があるとき（`paintPracticeBtn`）。
- グループ（`.mgroup[data-fold]`）: **Tempo**（Tempo・Metronome・Count-in）、**Loop**（A-B・Repeat・Ranges）、**Score**、**Recording**（録音があるときだけ）。見出しの名前（`.mfold`・▾/▸）を押すと開閉し、畳むと `.mbody` だけ隠れて見出しの All・フェーダーは使える。**開閉は楽譜ファイルごとに覚える**（オーナー要望 2026-11-17 第1290）: 拡張がワークスペースの状態に A-B の範囲と並べて置き（`panelFolds`・`lilysharp.panelFolds:<path>`・Speed and pitch の開閉は `_sp`）、描き直しのたびにページへ送る。**そのファイルで初めて開くときは全グループを畳む**（Speed and pitch も閉じる・`applyFolds`）。開いたまま別のファイルに切り替わればそのファイルの開閉に替わる。ページは同じファイルの送り直しでは手元の開閉を優先する（保存が届く前の古い写しで巻き戻らない）。
- **畳んだときの 1 行**（オーナー要望 2026-11-17「省略表示したとき、重要なボタンだけ一行で」「オクターブだけ省略した状態でも出して」）: Score と Recording は見出しがそのまま（All・フェーダー）。Tempo は畳むと見出しにテンポのスライダーと値・Metronome・Count-in、Loop は A-B・Repeat（`.mmini`・開いているときは出さない）。Speed and pitch は畳んだ行にオクターブの −・値・+（`.moct`）。Speed and pitch と録音の状態の行は Recording の畳まれる部分の外に置き、Recording を畳んでも出る（オーナー要望 2026-11-17。畳むと隠れるのは録音のパートの行だけ）。どれも中の本物の写し（`data-mini`＝押す・動かすと本物を押す・動かす、`data-mini-text`＝本物の文字）で、状態は `syncMinis` が本物から写す（`showPractice` と `showMixerHead` の後）。Speed and pitch の行の中のボタンは `preventDefault` で開閉を起こさない。パネルの最小幅は画面を超えない（`min(400px, 100vw - 16px)`）、畳んだ見出しの名前は幅を詰め、狭ければ折り返す。
- 実物の VS Code（Lab `p1289/e2e/cdp-mixer.mjs`）で、ミキサーの前の確認すべてが 1 つのパネルで通り、Tempo と Loop を畳むと高さが 33・37 px になり状態に `{tempo: true, loop: true}` が残ること、畳んだ行の Metronome・A-B・テンポのスライダー（80%）が本物を動かすこと、Speed and pitch を閉じたままオクターブの + で +1 になること、を確かめた。

## 7. Shift+クリックで B（第1289）

オーナー（2026-11-17）:「プレビューの楽譜の小節を shift+click したら B の旗を配置するのはどうかな」。小節の Shift+クリックは楽譜の上での範囲選択（2026-10-25 の要望）に使っていたが、オーナー決定で「現在の範囲選択の操作はサポートしないことにする。エディタで範囲選択できれば十分だ」。

- 小節（または音符）の Shift+クリック＝**その小節の右の小節線**に B（`setB(m, true)`＝その小節まで範囲に入る。クリックした小節を範囲に入れる A とそろう＝オーナー決定 2026-11-17。初めは左の小節線だった（オーナー「shift+click した小節の左側の小節線に B の旗を立てる方が自然」）が、同じ日に「クリックした位置のすぐ右側の小節線をターゲットに動く方がいい」と改めた＝M5 をクリック・M8 を Shift+クリックで M5〜M8）。（各行の最後の小節線の右の余白の Shift+クリックで B、クリックで A を置く操作もあったが、B が右の小節線になってその行の最後の小節・次の行の最初の小節のクリックと同じになったので外した＝オーナー決定 2026-11-17）。B の小節線が A の小節線と同じか前なら B はそこ・A はその 1 小節前＝Shift+クリックした小節だけ（オーナー要望 2026-11-17「Shift+クリックは B の旗を動かす意図」＝クリックで B より後ろを選んだときと同じ形。それまでは A と B が入れ替わって B が元の A の小節線へ行った）。**B の旗の立つ小節線**＝範囲の最後の小節の Shift+クリックは B を消す＝A-B オフ（A-B のボタンと同じ。B の位置は覚えていて、次にオンにすると戻る。オーナー要望 2026-11-17）。A-B はオンになる。鳴らしている途中なら今の位置から続ける（`setAb` → `replayIfPlaying`）。クリックは今までどおり A。
- 楽譜の Shift+クリック・Shift+ドラッグでの範囲選択（`extendSelectionToBar`・Shift+ドラッグの処理）は外した。Shift を押したままの押下は文字の選択を起こさない（`preventDefault`）。
- 実物の VS Code（Lab `p1289/e2e/cdp-shiftb.mjs`）で、m2 をクリック → A=2、m5 を Shift+クリック → B=4（m5 の左の小節線）・A-B オン、m7 → B=6、m0 → A=0・B=1（入れ替わり）、もう一度 m0 → 0〜0、最初の行の右の余白 → B=3（その行の最後の小節）、最後の行の右の余白 → B=151（曲の最後）、楽譜の選択は起きない、を確かめた。

## 8. 周ごとのカウントイン（第1290・§1 4）

- **形**: Count-in と Repeat がオンなら、ループの一覧は周ごとに「カウント 1 小節 → 音楽」（`loopNotes` の `gap`＝`{ lead, clicks }`。中身は最初のカウントインと同じ `countIn([], 0, spanStart)`＝範囲の最初の小節のクリック・弱起ならカウントの終わりに重なる）。周の長さは `loopRound + loopGap`、一覧は 0 から最初の周のカウントで始まり `countInFix = loopGap`。Count-in オフなら `loopGap = 0`＝今までどおり継ぎ目なし。Repeat オフ（A-B 1 回・全体 1 回）は今までどおり最初に 1 回だけ。
- **位置の読み**: 一覧の時刻 → 周の中の音楽の時刻は `loopPlace`（純関数）1 か所＝`placeNow()`。カウント中は音楽の 0（ヘッダは A の時刻＝最初のカウント中と同じ）と、カウントのどこか（`counting`）。読む所はヘッダ（`playbackScoreSeconds`）・旗やリピートを動かしたとき（`resumeHere`）・テンポなどの変更（`practiceChanged`）・書き換えの次の周（`refreshLoop`＝周の継ぎ目は一覧の時刻で `(loopRound + loopGap)` ごと）。作り直しはカウントの途中ならカウントの同じ所から（`loopOffset`）、音楽の途中ならそこから。声の区間（`voiceCues` の `gap`・`voicePlan.gap`）と終わりの時刻も同じ周の長さ。**鳴らしている途中に Count-in を切り替えたら、ループ中は今の位置から作り直す**（次の周から効く。ループでなければ従来どおり次の ▶ から）。
- **録音（Claude の判断）**: 最初のカウントインの間も録音は流れる（`recording-design.md` §1 7）ので、各周のカウントも同じに＝録音のループを `(origin − loopGap)` から `origin + loopRound` へ広げた（A の前のその長さが流れる）。録音の 0 より前にかかるとき（A が最初の小節で、録音の最初の小節線が 0 に近い）は無音。伸縮のエンジン（Signalsmith）は 0 より前を無音として読み自分でループするのでそのまま、素のバッファ再生（速さ 1）は 0 より前からループできないので周ごとに別の source を 10 分ぶん（最大 500）先に並べる（`RecordingPlayer.play` の `rounds`）。「カウントの間は録音を黙らせる」が良ければ、そこだけ変える。
- 網: `playbackCore.test.ts`（`loopNotes` の gap・`loopPlace`・`voiceCues` の gap）、`previewRanges.test.ts`（ヘッダの位置・録音のループ・形）。npm 1232 合格。
- 実物の VS Code（Lab `p1290/e2e/cdp-countin.mjs`・`go.ps1 -Ws ws|ws2`・4 小節の譜面と小節線にクリックの入った録音）: 一覧のクリックが周ごとに 4 拍（`ws2`: 0・6・12・18 s、音楽は 2・8・14 s）、ヘッダはカウント中 A の時刻、録音のクリックが期待の時刻 +27 ms（出力の遅れ・一定）——録音の 0 より前から始まるループ（素の再生、`rounds` 100 本: 2.027・4.027・8.027・10.027・14.027 s）も、録音の中のループ（2.027〜16.03 s の 6 s おき）も、伸縮のエンジン（`ws`・×1.125）でも。Count-in の切り替え・一時停止と再開・Repeat オフも。ページのエラー 0。
