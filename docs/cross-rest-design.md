# 休符の `@cross`（隣の段へ移す休符）

オーナー決定 2026-11-21（第1350）: **休符に書いた `@cross` も、音符と同じく休符を隣の段へ移す**
（LilyPond の `\change Staff` と同じ。`lysc ly` の双子は以前から移していた）。

## 1. 決定前の状態（第1350 の実測・Lab `sessions/p1350/rest`）

| 書き方 | `lysc check` | 双子の `.ly` と LilyPond 2.26.0 | Lily# の譜面 |
|---|---|---|---|
| `rh { e''2 e''2 } lh { c4 r4@cross c2 }` | 何も言わない | `\change Staff = "rh" r4`＝上の段の −2.0 | 下の段に残る |
| `lh { c4 grace { r16@cross e'16@cross } c4 c2 }`（c1） | 何も言わない | 休符も上の段・上の段の e'' を避けて +5.0 | e' だけ上の段へ・休符は下の段の +3.0 |
| `lh { c4 grace { r16 e'16@cross } c4 c2 }`（c2） | 何も言わない | 休符は下の段の +3.0 | 同じ（一致） |

譜面だけが休符の `@cross` を黙って捨てていた: 音符の印は `DecorateSoundingItem` が付け
（`MusicItem.CrossWritten`）、`MoveCrossStaffNotes` は `NoteItem`／`ChordItem` だけを移す。

## 2. 規則

1. `@cross` を書いた休符は、音符と同じ相手の段（大譜表ならもう一方の手）に描く。時刻・声部・
   連桁はその声部のまま。`a4@rest@cross` のように高さを書いた休符は、音符と同じく相手の段の
   音部記号で読み直す。
2. 移った休符の上下は、**移った先の段の** Rest_collision が決める（LilyPond の休符は
   `\change Staff` の後、その段の Rest_collision に入る）: 向きは休符自身の声部の向き、無ければ
   その列の向き＝頭の無い符幹の既定（下）。避ける相手は、その瞬間に移った先の段で鳴っている音
   （その段の声部の音と、その段へ移ってきた音）。同じ瞬間の同じ向きの列は全体（符幹も）、
   それ以外は根元の頭 1 つ（第1349 `RootHeadPosition`）。
3. 装飾音の列の中の休符は、列が丸ごと移るとき（本体の全部の音に `@cross`＝第1122）に、
   その休符も `@cross` を書いていれば移る。書いていなければ元の段に残る（c2・LilyPond と同じ）。
   列が移らないときの休符の `@cross` は移さない（音符の一部だけの `@cross` と同じ LYS4020 の扱い）。
4. 移った休符は元の段の Rest_collision・輪郭には入らず、移った先の段の輪郭に入る。

## 3. 段取り

- **段 1**: 普通の休符。集める段階の印（`CrossWritten`）・`MoveCrossStaffNotes` の移動・
  移った先の段での衝突（§2-2）・描く Y・移った先の段の輪郭。
- **段 2**: 装飾音の列の休符（§2-3）と、`GraceSeeds.Foreign` が休符のずらしを読むこと
  （leftovers 第1237 ⑵）。
- **段 3**: 移った休符に付いた印（記号・強弱・連符の括弧・休符の上の文字）の座標、MusicXML の
  `<staff>`、連桁が移った休符を避けること。
- 各段で LilyPond の双子と測る（`sessions/p1350/rest` の型）。

## 4. 経過

- 第1350: 決定と実測（§1）。段 1 と段 2 を `01497654d` で実装（`CrossStaffRestTests` 7 本・Lab `p1350/rest` の 8 形が LilyPond と 0.01 以内）。段 3 の MusicXML の `<staff>` は元から正しかった（書き出しはソースの `@cross` を読む）。
- 第1351: 記号は `ScriptsOnTheirNotesStaff` の入口が `RestsCrossedIn` も見るようにして閉じた（Lab `p1351/marks` m1）。
- 第1352: 強弱と文字は `DynamicsOnTheirNotesStaff` が音の立つ段へ付け替えて閉じた（移った音符も同じ・ヘアピンの線に入った強弱は線の段のまま。Lab `p1352/marks` q2・m2・m3 が LilyPond と 0.01 以内）。ついでに休符の上の記号の X（休符の幅の中央）と、別の声部に押された休符を記号が避けること（k1・k3・k4・k5）も閉じた。
- 第1353: 連桁と移った休符。自動の連桁は休符で切れる（LilyPond も同じ）ので、関わるのは `[ ]` で休符を囲んだ連桁だけ。`CalculateRestShifts` が連桁を元の段の座標で読み、低音の下の連桁が高音の休符を +2.0 へ押し上げていた（b5: LilyPond −1.0・b8: −3.0）→ 休符の立つ段の座標で読む（Lab `p1353/beam`）。残る形: 両段にまたがる連桁（b7 `c8[ r8@cross g'8@cross c8]`）は LilyPond +4.0（高音の上）／Lily# −6.5（連桁の下）。LilyPond は休符の棒の向きを連桁の向きと別に決める。
- 連符の括弧（m4）は LilyPond の絵が括弧を高音の譜の中へ通し、e'' と重なる（Lab `p1353/m4/lp.png`）。写すかどうかはオーナー判断。
- 残り（段 3）: 装飾音の列のスラーの障害物（`GraceRestShift`）は元の段の座標／列が移って休符が残る形（c2）の休符は、どの段の輪郭にも入らない（以前は移った先の段に誤って入っていた）。
