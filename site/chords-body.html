01

Chord names

A chord name is typed the way it prints — C, Am, Dm7, G7, Bb7/D, F#m7-5 (an altered tension takes + or -, because # and b belong to the root). There are two places to write one:

  • A chords row holds a progression. Placed directly above a staff in the score, it aligns over that staff; entries carry no durations — one entry takes the bar, two in 4/4 take half each.
  • @chord(NAME) puts a name on one note.

A name alone draws no diagram. That is the rule the rest of this page builds on: a diagram appears where you ask for one.

Spelling, the registered qualities, Roman degrees (Imaj7), as roman and the name a bare @chord derives from its notes are in the manual's Chords and chord rows.

02

A shape draws a diagram

Write the chord's shape in parentheses after its name — C(x32010) in a row — and a chord diagram is drawn under the name, between the name and the staff. The bars widen to make room.

In a shapeMeans
one character per stringfrom the low string up: x32010 is low E muted, A at the 3rd fret, D at the 2nd, G open, B at the 1st, high E open
xa muted string — drawn as a cross above the grid
0 or oan open string — drawn as a ring above the grid
a digitthe fret. A shape that reaches past the 4th fret is drawn from its lowest fret, labelled 3fr, 8fr … as LilyPond draws it
-10- … -15-a two-digit fret, with a - on each side: 8xx88-11, xx-10-12-13-11. A - between every string reads the same (x-x-10-12-13-11), so a chord chart's spelling can be pasted in

Between dashes, exactly two digits are one fret, so frets 10, 9, 9 are written 10-9-9 (10-99 would be fret 99, and warns). Shapes are lower case, like every value word. A shape of the wrong length, a doubled or dangling -, or a fret above 15 warns (LYS1038), naming the fix; the name still draws.

A shape is routed by its string count, so one chord can carry a shape for each instrument that might draw it — F(133211 2010) is the guitar's six strings and the ukulele's four. When two tunings have the same count, a tuning word names which shape is whose: F(guitar 133211 guitardropd 333211).

03

On a note, and with no name

On a note the shape follows the name, inside the parentheses: @chord(C x32010). The words after the name are its shapes — which is why @chord(C 7) is C with a (too short) shape, not C7: write @chord(C7).

WrittenDraws
@chord(C)the name only
@chord(C x32010)the name and its diagram
@chord(x02210)the diagram, and a name read off the shape's notes (Am)
@diagram(x24442)a diagram with no name at all — not a chord symbol, so it always draws. .down puts it under the staff

04

The notes on the staff

A diagram shows a shape; chord(NAME SHAPE) plays it. It is a music item, written where a note or a <…> chord would be, and it writes each sounding string as a note — the string's open pitch plus its fret, on the part's instrument — with its string number, so a tab of the part shows exactly that shape. chord(C x32013)1 on a guitar is C3 E3 G3 C4 G4 for a whole note.

  • It takes what a chord takes after it: a duration, dots, ties, slurs, beams, articulations, dynamics; a bare duration or q repeats it.
  • It draws no name of its own. A bare @chord on it adds the item's name and diagram: chord(Am x02210)2@chord.
  • Its pitches are absolute — octave marks after the ) are an error; play it higher on the neck instead. The note after it reads its lowest note.
  • The shape is required: chord(C) warns — write a shape: chord(C x32010) — and keeps its time as a spacer.

A chord name belongs to the beat, not to a note, so a rest, a spacer or a full-measure rest takes one, diagram and all: s1@chord(C x32010) is an intro bar over silence, r1@chord(G 320003) a rest bar that still names its chord. (A bare @chord there has no notes to name, and says so: write the name.)

String numbers, \N and the tab staff itself are in the manual's Tablature.

05

Which instrument, and every chord

A diagram is drawn for one tuning. Which one is decided per score, strongest first:

  1. The score's layout: layout { chordDiagrams ukulele } — any word a tab's tuning takes (guitar, ukulele, mandolin, guitardropd, bass, …). chordDiagrams none draws no diagram at all, written shapes included.
  2. Else the part's instrument, when it is fretted: for an @chord, the part whose note carries it; for a row, the staff the row stands directly above.
  3. Else the guitar — a lead-sheet row with no staff under it, or a staff that frets nothing.

So one source prints a guitar book, a ukulele book and a piano score, each from its own score:

layout uke   { chordDiagrams ukulele }
layout piano { chordDiagrams none }
part melody { clef treble }
section A {
  melody { c'1@chord(C x32010) | }
  chords prog { F(guitar 133211 ukulele 2010) | }
}
form main { A }
score main         { chords prog  staff melody }               // guitar: C and F
score main "uke"   { layout uke    chords prog  staff melody } // ukulele: F only
score main "piano" { layout piano  chords prog  staff melody } // no diagrams

A shape the diagram's tuning cannot take (the guitar's six characters on a ukulele) is simply not used there.

all — a diagram for every chord

Writing a shape on every chord of a song is tedious when the shapes are the usual ones. The scope word all — after the tuning (chordDiagrams guitar all, chordDiagrams ukulele all) or alone (chordDiagrams all, the tuning then chosen as above) — makes every chord name in that score draw a diagram: the shape written for its tuning, else its usual shape. The usual shape is LilyPond's predefined one for that tuning (C x32010, F 133211; ukulele C 0003), else the first shape of Lily#'s own order. A chord with no shape at all on the tuning warns once, asking you to write one.

G7 above carries a written shape, 0212, and draws it; the other three draw the ukulele's usual shapes. Without all, only G7 would have a diagram.

06

When a shape is not the chord

A written shape is checked against the name it is written for (LYS1039, a warning — the shape still draws). Two things are asked: every note it sounds is a tone of the chord, and every tone the chord needs is there. The root and the perfect fifth may be left out; the 3rd, the 7th, an altered fifth and the tensions may not. The bass is not checked — an inversion is an ordinary shape.

c'2@chord(C x02210) c'2@chord(C7 x3201x) |
ShapeThe compiler says
@chord(C x02210)'x02210' sounds A C E, which is Am, not C (A is not a tone of C) - write @chord(Am x02210) or another shape.
@chord(C7 x3201x)'x3201x' for C7 lacks B♭ (the 7th) - fret B♭ or write another shape.

A shape with no name (@chord(x32010)), an @diagram and a Roman degree in a row are not checked. Nine of LilyPond's predefined shapes would fail this check (guitar D♯m xx4341, Faug and Baug among them), so Lily# does not use them as usual shapes.

07

Let the editor write the shapes

You rarely need to type a shape. In VS Code, put the caret on a chord — an @chord(Cm7) or a row's Cm7 — and press Ctrl+Shift+Up: its usual shape is written and the diagram appears. Press it again to walk through the other playable shapes, each one sounded as you go; Ctrl+Shift+Down walks back, and at the usual shape removes it again. Hovering a chord shows what it would draw. Hard stretch shapes are left out unless you ask for them.

The keys, the stepping order and the lilysharp.chordShapes.includeStretch setting are on the editor page.
