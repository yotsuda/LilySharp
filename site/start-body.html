Install

Lily# works inside Visual Studio Code, a free editor. Two downloads, a few minutes, and nothing else to set up — no programming and no command line. (For the curious: the extension brings its own runtime, compiler and fonts — Emmentaler, three SMuFL music fonts and the TeX Gyre text faces.)

A first score

New Score gives you this file, with the title selected so you can type over it:

title "Untitled"

tempo 100
time 4/4
key c major

part melody {
  clef treble
  section A { c'4 d e f | g2 g | }
}

form { A }

score {
  staff melody
}

Read it from the top: the piece's settings, then a part (who plays) holding a section of music, then the form (in what order the sections play) and the score (what is printed). The music is c'4 d e f | g2 g |: note names, a duration after a note (4 a quarter, 2 a half) that the next notes keep until you write another, and | at each bar line.

  • Change a note — the score redraws as you type, not when you save. Put the caret on a note: it lights up in the score, and sounds.
  • Add a bar — type e4 d c2 | before the closing brace.
  • Hear it — press ▶ at the top of the preview. Alt+P plays the note under the caret, Alt+M the bar.
  • Make a mistake — type a bar that is too long. A squiggle appears; hover it to read what is wrong, and the lightbulb (Ctrl+.) fixes it where there is one obvious repair.
  • Export — Lily#: Export as PDF (or SVG, PNG, MIDI, MusicXML, LilyPond) from the command palette or the preview.

The lessons

Twelve short lessons live in the editor. On an empty line at the top level of a .lys file, type lesson and press Ctrl+Space: picking one puts it in the file. Each is a playable score with its steps marked in red in the preview — completion and the preview, notes and octaves, rhythm, keys, expression, form and repeats, lyrics, chords, piano, drums, a band, and a jazz chart. The same lessons are on the Learn pages.
