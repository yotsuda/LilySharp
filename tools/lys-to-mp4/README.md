# lys-to-mp4 — .lys から楽譜動画（.mp4）を作る

`.lys` の楽譜を、**彫った紙面の上で鳴っている音符が光る、音つきの動画**にする。
記事やサイトに載せるデモ動画（YouTube の限定公開など）を作るための道具で、リリースには入らない。

エディタの **Export as MP4 Video** と同じ絵を描く（どちらも `LilySharp.Core/Export/ScoreVideo.cs` を呼ぶ）。
エディタで足りるならそちらでよい。この道具は、動画の大きさ・色・紙面の設定を変えたいとき、
コマンド一つで作りたいときに使う。

- 紙面は lysc が彫るページそのまま。既定は A4 縦。
- 最初は 1 ページ目を映し、次のページに印刷された音が鳴った時点で、画面全体をそのページに切り替える。
- 光るのは**鳴っている符頭だけ**（既定はオレンジ）。小節などは塗らない。光る長さは音の長さと同じ。
- 音は、VS Code のプレビューと同じ合成器（spessasynth）と同じサウンドフォント（MuseScore_General.sf3）で鳴らす。

## 必要なもの

| もの | 用途 |
|---|---|
| .NET 10 SDK | lysc と描画プログラムのビルド |
| Node.js、`editors/vscode` での `npm install` 済み | 音の書き出し（spessasynth_core を使う） |
| ffmpeg / ffprobe（PATH 上） | 無音の検出と動画の書き出し |
| PowerShell 7 | 下のスクリプト |

## 使い方

リポジトリの直下で:

```powershell
./tools/lys-to-mp4/New-ScoreVideo.ps1 ~/Downloads/Haru-no-Kaze.lys
```

`.lys` の隣に同じ名前の `.mp4` ができる。すでにあれば止まるので、上書きするときは `-Force` を付ける。
約 100 秒の曲で 30 秒ほどかかる（大半はビルド）。

### オプション

| 引数 | 既定 | 意味 |
|---|---|---|
| `-Out` | `.lys` の隣 | 書き出す `.mp4` |
| `-Width` / `-Height` | 1240 / 1754 | 動画の大きさ。ページは形を保って収め、余りは白 |
| `-Fps` | 30 | フレームレート |
| `-Lead` | 1.5 | 鳴り始める前に楽譜だけを映す秒数 |
| `-Color` | `F57800` | 光る符頭の色（RRGGBB） |
| `-Set` | なし | 紙面・レイアウトの設定（lysc の `--set` と同じ書き方） |
| `-Scale` | 2.0 | ページを彫る解像度（lysc png の `--scale`） |
| `-SoundFont` | 拡張の MuseScore_General.sf3 | 音色（.sf2 / .sf3） |
| `-WorkDir` | 一時フォルダに新規作成 | 途中のファイルの置き場所 |

横長の動画にするなら、紙も 16:9 にする:

```powershell
./tools/lys-to-mp4/New-ScoreVideo.ps1 song.lys -Width 1920 -Height 1080 -Set 'paperWidth=320mm','paperHeight=180mm'
```

紙を変えると段の配分も変わる。最後のページが 1 段だけになるなどで見栄えが悪いときは、
`-Set 'staffSpace=1.5mm'` のように譜表を小さくすると、ページ数が減ることがある。

## 中で何をしているか

`New-ScoreVideo.ps1` が次の 5 段を順に行う。途中のファイルは `-WorkDir` に残る。

1. **ビルド。** `LilySharp.Cli`（lysc）と `ScoreVideo` を Release でビルドする。
2. **MIDI を書く。** `lysc midi`。
3. **音を作る。** `render-audio.mjs` が MIDI を spessasynth_core で鳴らし、WAV にする。
   `lysc wav` を使わないのは、それが読めるのが .sf2 だけで、拡張が持つのは .sf3 だから。
4. **絵を描く。** `ScoreVideo` が言語サーバの再生 API（`GetPlayback`、プレビューが鳴らすのと同じ一覧）から
   音ごとの発音時刻・長さ・ソース上の位置を得て、`LilySharp.Core.Export.ScoreVideo` に渡す。
   Core はページの絵と符頭の位置を彫り、「どのページを映し、どの符頭を光らせるか」が変わるたびに 1 枚描く。
   絵と表示時間の一覧が `frames/frames.txt`。
5. **書き出す。** ffmpeg で絵と音を重ねる。音は `-Lead` の分だけ遅らせる。
   最後の無音が始まる 1 秒後で切ってフェードアウトし、音量を −16 LUFS に揃える。

### 音と符頭の突き合わせ（Core の ScoreVideo）

- 和音の音は、再生の一覧では和音の `<` の位置で届き、符頭は音ごとの位置で描かれる。
  そこで符頭を、構文木でそれを囲む和音の開始位置にも結びつけて照合する。
- 同じ節を form が二度演奏し、楽譜にも二度印刷されている場合がある。そのときは再生の一覧の `O`（何番目の印刷か）と、
  符頭が読む順で何番目の小節にあるかを対応させる。

## 制限

- 描くのはファイルの**最初の score** だけ（エディタの書き出しは、選んだ score か全 score）。
- 映るのは彫った紙面だけで、エディタの画面やソースは映らない。エディタを見せたいなら画面を録る。
- テンポの揺れは MIDI に書かれた分だけ反映される。光る時刻と音は同じ再生データから作るのでずれない。
